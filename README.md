# Leave Review Worker

Віртуальний працівник (бонус WS10, шлях 2B): перед тим, як менеджер школи вирішить по заявках на відпустку, працівник читає чергу й готує брифінг із позначками, де потрібна увага. Рішення завжди за людиною.

**Принцип: рахує й перевіряє код, модель пояснює.** Дні, баланси, перетини, дні закриття й підозрілі коментарі рахує `src/checks.ts`. Модель отримує готові прапорці й пише менеджеру пояснення. `src/report.ts` ще раз звіряє її відповідь із тим, що порахував код.

Повний опис ролі, меж, golden-даних, вартості й того, що зламалось: [`docs/worker/README.md`](docs/worker/README.md). Журнали й звіти живих запусків: [`docs/worker/runs/`](docs/worker/runs/).

## Запуск

Потрібен Node 24.

```bash
npm i
npm run check        # типи
npm test             # 35 офлайн-тестів, модель не викликається
npm run dry-run -- --set problems   # конфігурація, прапорці, межі, БЕЗ моделі й ключа
```

Живий запуск: скопіюйте `.env.example` у `.env`, вставте свій безкоштовний ключ OpenRouter, далі:

```bash
npm start -- --set clean        # або problems, injection
```

Коди виходу: `0` — відповідь пройшла перевіряльник; `1` — перевіряльник знайшов проблеми; `2` — запуск не відбувся.

## Дані

Усе синтетичне: працівники `staff-NN@example.test`, закриття й баланси в `data/`, три набори заявок у `data/<набір>/requests.csv`. Справжніх людей і даних немає.

## Джерело й ліцензія

Каркас (хук-межа запису, `resolveConfig` для OpenRouter, структура тестів) узято з [koldovsky/2026-quitcode-10-ai-features-hw](https://github.com/koldovsky/2026-quitcode-10-ai-features-hw), `materials/worker-agent-sdk` (MIT). Роль, дані, перевірки, перевіряльник, схема, тести й виправлення (`$schema`, чужа авторизація у середовищі) — власні.

## Ризики шляху 2B

Anthropic не підтримує маршрутизацію Claude Code на не-Claude моделі через шлюзи; працює експериментально й може зламатись у будь-якому кроці. Ключ OpenRouter тримайте лише в `.env` (він у `.gitignore`) або в GitHub Secrets.
